# Kevin Nowacki — Luxury Real Estate Website

Premium React + Vite real-estate landing page concept for Kevin Nowacki / Sidorova Inwood Team / RE/MAX.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
